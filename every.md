##  EVERY {#GUID-C34D8A50-3050-4F32-941A-8C2512DEC62D} 

Syntax 

  


![Description of every.eps follows](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img/every.gif)[ Description of the illustration every.eps ](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img_text/every.md)

  


Purpose 

` EVERY ` returns ` 'TRUE' ` if the *boolean_expr* evaluates to true for every row that qualifies. Otherwise it returns ` 'FALSE' ` . You can use it as an aggregate or analytic function. It is the same as the function ` BOOLEAN_AND_AGG ` .
