##  TO_NCHAR (boolean) {#GUID-4F0853D4-C661-4DF2-8B67-F5207F2A86CF} 

Syntax 

  


![Description of to_nchar_boolean.eps follows](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img/to_nchar_boolean.gif)[ Description of the illustration to_nchar_boolean.eps ](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img_text/to_nchar_boolean.md)

  


Purpose 

Use ` TO_NCHAR(boolean) ` to explicitly convert a boolean value to a character value of ` 'TRUE' ` or ` 'FALSE' ` . 

> **note:** See Also: 

  * *CAST* for conversion rules. 

  * *Boolean Data Type* for more details on the built-in boolean data type.
