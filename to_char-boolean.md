##  TO_CHAR (boolean) {#GUID-B9923922-AD87-4C7A-BC9A-3A3BC2D6AA2E} 

Syntax 

  


![Description of to_char_boolean.eps follows](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img/to_char_boolean.gif)[ Description of the illustration to_char_boolean.eps ](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img_text/to_char_boolean.md)

  


Purpose 

Use ` TO_CHAR(boolean) ` to explicitly convert a boolean value to a character value of ` 'TRUE' ` or ` 'FALSE' ` . 

> **note:** See Also: 

  * *CAST* for conversion rules. 

  * *Boolean Data Type* for more details on the built-in boolean data type.
