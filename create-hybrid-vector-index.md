## CREATE HYBRID VECTOR INDEX

Syntax

  


![Description of create_hybrid_vector_index.eps follows](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img/create_hybrid_vector_index.gif)[Descriptionof the illustration create_hybrid_vector_index.eps](https://docs.oracle.com/en/database/oracle/oracle-database/23/sqlrf/img_text/create_hybrid_vector_index.md)

  


Semantics

This command is part of the Oracle Text product.

Use the `CREATE HYBRID VECTOR INDEX` statement to create a hybrid vector index, which allows users to index and query documents using a combination of full-text search and similarity search to achieve higher quality search results. 

For full semantics and usage details, refer to [Oracle Text SQL Statements and Operators](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/23/sqlrf&id=CCREF-GUID-22B07106-419E-4C55-B4E1-3FD691E033BC) of the Oracle Text Reference.
