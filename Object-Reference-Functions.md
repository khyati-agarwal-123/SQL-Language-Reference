## Object Reference Functions 

Object reference functions manipulate `REF` values, which are references to objects of specified object types. The object reference functions are: 

  * [DEREF](DEREF.html#GUID-E551FFE4-619F-40CE-8303-683EFA3EB28F)
  * [MAKE_REF](MAKE_REF.html#GUID-926B9963-5387-4781-88D5-A005334C1F2A)
  * [REF](REF.html#GUID-B7622138-6EB6-4203-B5E7-91CAD52E9DB1)
  * [REFTOHEX](REFTOHEX.html#GUID-3F8A9932-063D-4EF1-85B7-03D823F6AC09)
  * [VALUE](VALUE.html#GUID-BEB129A5-525F-4EEF-A79C-261954056234)
